🔹 Diamond Problem in Java

The Diamond Problem occurs in multiple inheritance when a class inherits 
from two classes that have the same method, causing ambiguity about which method
to use.

Java does not support multiple inheritance with classes** to avoid this
problem.
---------------------------------------------------------------------------

🔹 Example of Diamond Problem (Concept)

If:

* Class A has method `show()`
* Class B and Class C extend A
* Class D extends both B and C

Then D gets two copies of `show()` → ambiguity occurs
---------------------------------------------------------------------------


🔹 How Java Solves It?

Java allows multiple inheritance **only through interfaces**.
If two interfaces have the same default method, the implementing class 
must override it explicitly.

---------------------------------------------------------------------------


🔹 Short Interview Answer:

> The Diamond Problem occurs in multiple inheritance when a class inherits the
 same method from two parent classes, causing ambiguity.
  Java avoids this by not supporting multiple inheritance with classes and 
  resolving it using interfaces with mandatory overriding.
